# Product Iteration｜継続的なUX改善と意思決定

## 初期のアイデアから継続利用できる製品へ

「えきよみ」では、初回利用、音声選択、連続再生、ビジュアルアイデンティティを段階的に改善しました。対象ユーザーの操作しやすさと、Web・iOSでの体験の一貫性を重視しています。

## 01｜初回チュートリアル

**課題：** 初めてでも路線選択・駅名読み上げ・次駅操作を理解できること。

**改善：** 複数ステップのチュートリアルを導入し、設定画面から再確認できる導線も設置。

**訴求能力：** UX Design / Feature Definition / Onboarding

## 02｜音声選択と連続再生

**課題：** 音声を選びやすく、連続した駅名読み上げも楽しめること。

**改善：** 音声の選択肢を整理し、サンプル音声を確認できるUIを追加。「かけながし」機能で次駅案内を自動再生し、駅や方向の変更などで停止する操作ルールも整備。

**訴求能力：** User Journey Design / Interaction Design / Requirements Prioritization

## 03｜アプリのブランド表現

**課題：** アプリアイコン、Web、iOS、共有時のプレビューに一貫した表現を持たせること。

**改善：** 電車と吹き出しを組み合わせたアイコンを選定し、各プラットフォームに展開。

**訴求能力：** Product Positioning / Design Decision / Cross-Platform Consistency

## 自身が担ったプロダクトマネジメント

- **Define：** 改善の目的とユーザー体験上の課題を明確化
- **Prioritize：** 機能・UXの優先順位を整理
- **Orchestrate：** AIを活用した実装・改善を推進
- **Review：** 変更内容とプロダクトコンセプトの整合性を評価
- **Deliver：** Web・iOS双方での提供まで推進

## この事例で示す能力

**Product Leadership / UX Strategy / Feature Prioritization / AI-Assisted Delivery / Cross-Platform Experience**

単発の機能開発ではなく、**ユーザー価値と製品全体の一貫性を軸に改善を継続する能力**を示しています。
